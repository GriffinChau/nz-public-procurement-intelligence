# Excel dashboard workbook

The workbook `NZ_Public_Procurement_Awards_Intelligence.xlsx` is the interactive companion to the [public-data analysis](../README.md).

It uses **52 publicly disclosed entries** from the first page of Auckland Transport's FY2026 awarded-contract report. The reporting cut-off is the publisher's selected July 2025 record window, **not** a live dataset or a full financial-year extract.

The workbook contains `DASHBOARD`, `AWARDS_DATA`, `SUPPLIER_SCORECARD`, `CATEGORY_EXPOSURE`, `DAILY_TREND`, `DATA_QA`, `KPI_DICTIONARY`, `SOURCE_LOG` and `HOW_TO_USE`. Consult the [walkthrough](../docs/03_workbook_guide.md) and [provenance](../docs/05_sources_and_limitations.md).

**Measure boundary:** Published award value is not invoiced spend or cash paid. No verified goods receipts, supplier OTIF, purchase order lateness or realised savings are available. Source and summary CSVs remain independently reviewable without Excel.
