# Evidence-based findings and proposed actions

**Scope:** 52 first-page rows from an Auckland Transport FY2026 awarded-contract PDF, dated 1–10 July 2025. These are actual public disclosures but neither annual totals nor cash spend.

## F1 - One outlier drives the sample

The 52 entries sum to **NZ$15,111,059.25**. One NZTA-related national-land-transport-fund/frontloading agreement is **NZ$9,250,200 (61.2%)**. A supplier-value ranking can mislead when agency-related funding arrangements are compared with third-party market procurement.

**Suggested action:** Investigate the agreement type; add a controlled classification (external procurement / intra-government arrangement / pending review) only with supporting source evidence. Report both totals with and without the item, never delete it silently.

## F2 - Procurement number is not an entry key

There are **52 entries but 48 distinct procurement numbers**. Three identifiers repeat, yielding four excess occurrences.

**Suggested action:** Use row/award-line identifiers, retain the raw strings and examine amendments, descriptions and awardees before deduplicating.

## F3 - Supplier names need enrichment

The pilot has **40 supplier-name strings**, some visibly truncated in the official PDF.

**Suggested action:** For future entity-level comparisons, build an NZBN-backed supplier crosswalk, maintain original source strings and flag uncertain matches.

## F4 - Category codes need an authoritative dictionary

There are **7 source category codes**; the inspected page does not provide validated expansions.

**Suggested action:** Obtain the publisher's mapping before making category-specific sourcing claims.

## Interpretation boundary

The award publication cannot establish supplier on-time delivery, invoice settlement, bid fairness, realised savings, actual stockouts, or GST treatment. These are analytical investigation prompts, **not proven supplier quality results**.
