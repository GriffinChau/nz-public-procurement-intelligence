# Source provenance, rights and limitations

## Primary source

**Publisher:** Auckland Transport, New Zealand.

**Document:** FY2026 awarded contracts PDF, file name auckland-transport-latest-awarded-contracts-july-2026.pdf.

**[Official publisher PDF](https://at.govt.nz/media/xy2jwzgu/auckland-transport-latest-awarded-contracts-july-2026.pdf)** · **[Contracts-awarded landing page](https://at.govt.nz/about-us/procurement/contracts-awarded)**

**Extract:** First **52 records from PDF page 1**, source-created dates **1–10 July 2025**. The report has **35 pages**; this pilot is **not** the complete FY2026 dataset. Every record carries a one-based source-page value and the official PDF URL.

**Transcription:** Contract Award Value transcribed as NZD decimal, dates converted to ISO. Some supplier names in the PDF are truncated; strings are deliberately retained. source_row is a pilot-specific ordinal, not an identifier supplied by Auckland Transport.

## Additional sources researched but not used for the pilot's amounts

- [MBIE / NZ Government Procurement GETS Open Data](https://www.mbie.govt.nz/cross-government-functions/new-zealand-government-procurement-and-property/open-data): possible future source for tender/award, supplier, category and region CSVs.
- [NZ Government Procurement - data and reporting](https://www.procurement.govt.nz/data-and-reporting/): GETS disclosures should not be treated as financial-spend ledgers.

## Rights and scope

Public accessibility is not a guarantee of public-domain licensing. The project's MIT licence covers **original code and documentation only**; it does not relicense Auckland Transport's underlying material. Review publisher terms before bulk redistribution.

Award value does not mean paid spend, cash flow, invoice settlement, delivered value, PO commitment, supplier performance or realised procurement savings. Procurement identifiers are not unique across published rows; names are not NZBN-confirmed legal entities; category codes are uninterpreted. Date is **Contract Created Date**, not delivery or payment. The source does not declare GST treatment in the inspected PDF.

The fixed, nonrandom first-page sample cannot support financial-year population estimates. Source publications may be revised; preserve the edition and its provenance.
